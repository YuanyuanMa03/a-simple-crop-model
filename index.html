SIMPLE 作物模型

Soil-Plant-Atmosphere Interactions for Model Evaluation and Learning

土壤-植物-大气交互模型评估与学习 — Python 教学版

Python 实现 多作物支持 气象驱动 胁迫响应 CO₂ 施肥效应

1 模型概览

SIMPLE 是一个基于过程的作物生长模型，通过气象、土壤和管理输入来模拟作物每日生长与最终产量。

🌱

基于过程的模型

不同于统计模型，SIMPLE 从作物生理过程出发，模拟光截获、积温累积、生物量增长等逐日动态过程。

☀️

气象驱动

以每日最高温、最低温、太阳辐射和降水为核心驱动变量，计算积温、蒸散和干旱指数。

🌡️

多重胁迫响应

集成温度胁迫、高温胁迫、水分胁迫和 CO₂ 施肥效应，实现复杂环境条件下的产量模拟。

3 核心公式

SIMPLE 模型的关键数学公式，构成逐日模拟的物理基础。

有效积温 (Degree Day)
$$\text{dTT} = \max(\overline{T} - T_{\text{base}},\; 0)$$
每日有效积温 = 平均温度与基础温度之差（不低于0），累积形成 $\text{TT}$ 驱动物候发育。
日生物量增量
$$\Delta B = 10 \times \text{RUE} \times f_{\text{solar}} \times \text{SRAD} \times F_{\text{CO}_2} \times F_{\text{Temp}} \times \min(F_{\text{Water}},\; F_{\text{Heat}})$$
由辐射利用效率、光截获率、太阳辐射和各胁迫因子共同决定。
温度响应函数
$$F_{\text{Temp}} = \begin{cases} 1 & \overline{T} \geq T_{\text{opt}} \\[6pt] \dfrac{\overline{T} - T_{\text{base}}}{T_{\text{opt}} - T_{\text{base}}} & \overline{T} < T_{\text{opt}} \end{cases}$$
温度低于最适温度时线性增长，达到最适温度后响应值恒为 1。
水分胁迫响应
$$F_{\text{Water}} = \max\!\left(0,\; 1 - S_{\text{Water}} \times \text{ARID}\right)$$
ARID 干旱指数越大，水分胁迫越强，生物量积累越受抑制。
高温胁迫响应
$$F_{\text{Heat}} = \begin{cases} 1 & T_{\max} \leq T_{\text{MaxT}} \\[6pt] 1 - \dfrac{T_{\max} - T_{\text{MaxT}}}{T_{\text{ExtremeT}} - T_{\text{MaxT}}} & T_{\text{MaxT}} < T_{\max} < T_{\text{ExtremeT}} \\[6pt] 0 & T_{\max} \geq T_{\text{ExtremeT}} \end{cases}$$
最高温超过阈值 $T_{\text{MaxT}}$ 后线性下降，达到 $T_{\text{ExtremeT}}$ 时完全胁迫（值为0）。
CO₂ 施肥效应
$$F_{\text{CO}_2} = \begin{cases} 1 + \text{CO}_2\_\text{RUE} \times \dfrac{350}{100} & \text{CO}_2 \geq 700 \\[8pt] \max\!\left(\text{CO}_2\_\text{RUE} \times \text{CO}_2 \times 0.01 + 1 - 0.01 \times 350 \times \text{CO}_2\_\text{RUE},\; 1\right) & \text{CO}_2 < 700 \end{cases}$$
模拟大气 CO₂ 浓度升高对辐射利用效率的促进作用。
光截获动态 — 双逻辑曲线
$$f_{\text{solar}} = \min\!\left(f_{\text{solar}_1},\; f_{\text{solar}_2}\right)$$
$$f_{\text{solar}_1} = \frac{I_{\max}}{1 + \exp\!\left(-0.01 \times (\text{TT} - I_{50A})\right)} \qquad \longleftarrow \text{营养生长期上升支}$$
$$f_{\text{solar}_2} = \frac{I_{\max}}{1 + \exp\!\left(\phantom{-}0.01 \times (\text{TT} - (\text{Tsum} - I_{50B}))\right)} \qquad \longleftarrow \text{灌浆期下降支}$$
双逻辑曲线模拟光截获从低到高（营养生长）再从高到低（衰老）的完整动态过程。其中 $I_{\max}$ 为最大光截获率，$I_{50A}$、$I_{50B}$ 控制曲线拐点位置。

4 胁迫与响应曲线

交互式展示各胁迫因子和响应函数随输入变量变化的曲线。不同作物因物种参数差异而呈现不同响应特征，点击图例可切换显示。

🌡️ 温度响应曲线 FTemp

当 $\\overline{T} \\geq T_{\\text{opt}}$ 时 FTemp=1；低于最适温度时线性增长。小麦(Topt=15°C)对低温更敏感，玉米(Topt=28°C)需要更高温度才能达到最佳生长。

🔥 高温胁迫曲线 FHeat

Tmax 低于阈值 MaxT 时不发生胁迫；超过后线性下降至 ExtremeT 时完全胁迫。大豆(MaxT=36°C)比小麦(MaxT=34°C)更耐高温。

💧 水分胁迫曲线 FWater

ARID 干旱指数越大，水分胁迫越强。SWater 控制作物对干旱的敏感度：玉米(SWater=1.5)比小麦(SWater=0.4)对干旱更敏感。

🏭 CO₂ 施肥效应 FCO₂

模拟大气 CO₂ 浓度升高对辐射利用效率的促进。小麦(CO₂_RUE=0.08)对 CO₂ 升高响应比玉米(CO₂_RUE=0.01)更明显。

🌿 光截获动态曲线 fSolar — 双逻辑曲线

随积温(TT)推进，光截获率先上升（营养生长）后下降（衰老），形成典型的钟形曲线。不同作物的 I50A、I50B、Tsum 参数决定了曲线的形状和位置。

6 核心代码实现

选取模型中最关键的函数，展示 Python 实现逻辑。

core.py # 温度响应函数：计算温度对作物生长的影响因子 # 当平均温度 >= 最适温度时，响应值为 1（最佳条件） # 否则按线性插值计算：(Tmean - Tbase) / (Topt - Tbase) def temperature_response(tmean, tbase, topt): if tmean >= topt: return 1.0 else: return max((tmean - tbase) / (topt - tbase), 0)
core.py # 水分胁迫响应函数：基于 ARID 干旱指数 # ARID 越大表示越干旱，S_Water 控制作物对干旱的敏感度 def water_response(arid, s_water): return max(0, 1 - s_water * arid)
core.py # 每日生物量增量计算 — 模型的核心公式 # dBiomass = 10 × RUE × fSolar × SRAD × F_CO2 × F_Temp × min(F_Water, F_Heat) # 其中：RUE=辐射利用效率, fSolar=光截获率, SRAD=太阳辐射 # F_CO2=CO2施肥效应, F_Temp=温度响应, F_Water/F_Heat=胁迫因子 def calculate_daily_biomass(f_solar, srad, f_co2, f_temp, f_water, f_heat, rue): return 10 * rue * f_solar * srad * f_co2 * f_temp * min(f_water, f_heat)
core.py — 光截获双逻辑曲线 # 双逻辑曲线模拟光截获率随积温(TT)变化的动态过程 # fSolar1：营养生长期上升支，从低截获逐步增加 # fSolar2：灌浆期下降支，从高截获逐步降低（衰老） f_solar1 = min(1, fsolar_max / (1 + np.exp(-0.01 * (tt - i50a_prev)))) f_solar2 = min(1, fsolar_max / (1 + np.exp(0.01 * (tt - (tsum - i50b_prev))))) # 最终光截获 = 两条曲线的较小值 × 水分胁迫修正 result.loc[day, "fSolar"] = min(f_solar1, f_solar2) * min(result["fSolar_water"].iloc[day-1], 1)
